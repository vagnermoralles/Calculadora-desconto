# 🛒 Calculadora de Desconto Progressivo em Python
Este é um programa em Python para calcular o valor de desconto e o total a ser pago em uma compra.

---

## 📌 Regras de Negócio

O desconto é aplicado automaticamente com base nas seguintes faixas de valor:

| Valor da Compra | Desconto |
| :--- | :---: |
| Menor que R$ 200,00 | **5%** |
| Entre R$ 200,00 e R$ 299,99 | **10%** |
| A partir de R$ 300,00 | **15%** |

---

## 🛠️ Funcionalidades

- Leitura do nome do cliente e do valor da compra.
- Identificação automática da porcentagem de desconto.
- Exibição do valor economizado em reais (`R$`).
- Exibição do valor final atualizado a ser pago.
